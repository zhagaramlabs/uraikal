# Security policy

## Reporting a problem

Please don't open a public issue for a security problem. Report it privately instead:

- with GitHub's **Report a vulnerability** button on this repo's Security tab, or
- by email to hello@zhagaramlabs.com, with "Security: uraikal" in the subject.

Say what you found, how to reproduce it, and what it could let someone do. We'll reply as soon as we
can, keep you updated until it's fixed, and credit you if you'd like.

## What counts

- The `uraikal` library and command line, and the code that prepares and scores test sets.
- A way to read or reconstruct a **hidden test set** from this repo, a released file or a result.
- Secrets, personal data or recordings that shouldn't be in this repo or its releases.

## Versions

We fix the latest code on `main` and the latest PyPI release.
